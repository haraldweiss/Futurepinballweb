# Suggested Commands

## Dev
- `npm run dev` — Vite dev server (port 5173)
- `npm run build` — production build (Vite)
- `npm test` — run Vitest suite (691 tests)
- `npm run test:coverage` — tests with coverage report
- `npx tsc --noEmit` — TypeScript type check

## Electron
- `npm run electron:dev` — dev with Electron
- `npm run electron:build` — build desktop installers

## Lint
- `npm run lint` — ESLint
- `npm run lint:security` — security-focused ESLint

## Analysis
- `npx vite build --analyse` — bundle analysis
